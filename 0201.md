# Ejercicio 1 - Diseño con Tarjetas CRC

Supón que debes desarrollar un sistema de gestión de una biblioteca. El sistema debe permitir:

Registrar libros con título, autor, ISBN y número de ejemplares disponibles.
Registrar socios con nombre, número de socio y fecha de alta.
Gestionar préstamos: un socio puede tomar prestado un libro si hay ejemplares disponibles.
Devolver un libro prestado, actualizando los ejemplares disponibles.

### Tarjeta CRC: Libro

| Clase: Libro | |
| --- | --- |
| **Responsabilidades** | **Colaboradores** |
| Conocer su título, autor e ISBN | - |
| Conocer el número de ejemplares disponibles | - |
| Prestar un ejemplar (si hay disponibles) | `Préstamo` |
| Recibir la devolución de un ejemplar | `Préstamo` |

### Tarjeta CRC: Socio

| Clase: Socio | |
| --- | --- |
| **Responsabilidades** | **Colaboradores** |
| Conocer su nombre, número de socio y fecha de alta | - |
| Solicitar préstamo de un libro | `Préstamo` `Libro` |
| Devolver un libro prestado | `Préstamo` |


### Tarjeta CRC: Préstamo

| Clase: Préstamo | |
| --- | --- |
| **Responsabilidades** | **Colaboradores** |
| Conocer que libro y que socio están implicados | `Libro` `Socio` |
| Conocer la fecha de inicio del préstamo | - |
| Registrar la devolución del préstamo | `Libro` |


### 2. Para Libro, que debería ocurrir cuando se intenta prestar un ejemplar:

    Cuando se intenta prestar un libro se tienen que cumplir una serie de pasos:
    -Que haya un ejemplar disponible del Libro.
    -Si lo hay se presta y la clase Libro tiene que disminuir en uno sus ejemplares de ese libro. 
    -Aqui entra la clase Préstamo. El préstamo tiene que conocer que libro y que socio están implicados.
    -Si el préstamo no tiene éxito significa que no hay ejemplares por lo que los pasos anteriores no sucederían.(Al no haber ejemplares ya es un préstamo fallido).

### 3. Describe con tus palabras el siguiente flujo, indicando en cada paso qué clase actúa y qué colaboradores necesita:

    - Se da de alta un libro con 3 ejemplares. Actúa la clase ibro.
    - Se dan de alta dos socios. Actúa la clase Socio1 y Socio2.
    - El primer socio toma prestado el libro(¿tiene éxito?). Sí, tiene éxito al haber ejemplares. Participa la clase Socio1 y la clase Libro.
    - El segundo socio intenta tomar el mismo libro (¿tiene éxito?). Sí, tiene al seguir habiendo aún dos ejemplares. Participan la clase Libro y la clase Socio2.
    - El primer socio devuelve el libro. El número de ejemplares pasa a ser 2. Participan Socio1 y Libro. 
    - El segundo socio vuelve a intentar tomar el libro (¿tiene éxito?). Sí, tiene al haber aún disponibles dos ejemplares. Actúan la clase Libro y la clase Socio2.
